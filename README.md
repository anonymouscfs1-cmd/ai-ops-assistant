# AI Ops Assistant

An AI-driven operations assistant built for Alopias, developed as a learning project
to combine machine learning, LLM agents, DevOps, and IT service management into one working system.

## Goal

Alopias needs to predict demand/foot traffic and have an assistant that can answer
questions — partly from documentation, partly from live predictions generated by
a self-trained model.

## Phases

- [ ] **Phase 1 — Forecasting model**: prediction model for revenue/demand based on
  historical (or synthetic) data. Trains and evaluates a regression model.
- [ ] **Phase 2 — LLM agent with tool-calling**: assistant that queries documentation (RAG)
  AND can call the Phase 1 forecasting model as a tool.
- [ ] **Phase 3 — CI/CD & deployment**: automated tests, Docker build, and deployment via
  GitHub Actions to a VPS/cloud.
- [ ] **Phase 4 — Incident tracking**: logging moments where the assistant can't answer
  something, with severity levels (ITIL-inspired).

## Status

🚧 Working on Phase 1 — collecting/generating data and training the first model.
